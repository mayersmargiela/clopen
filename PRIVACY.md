# 隐私说明 / Privacy Notice

## 中文

Clopen 是本地 Windows 桌面应用。当前版本不包含账户系统、遥测、广告或云同步，也不会把用户的软件列表、组合配置或会话进程记录上传到 Clopen 维护者或第三方服务器。

配置保存在当前 Windows 用户的 `%APPDATA%\Clopen\config.json`。卸载便携版不会自动删除该配置；用户可以自行备份或删除。通过 GitHub Issue、Discussion 或安全报告主动提交的信息由 GitHub 按其政策处理，因此提交前请移除个人路径、用户名和不必要的软件列表。

如果未来加入任何联网功能，必须在启用前更新本说明，并在 Release Notes 中明确披露。

## English

Clopen is a local Windows desktop application. The current version has no account system, telemetry, advertising, or cloud sync, and it does not upload application lists, group configuration, or session process records to the Clopen maintainer or third-party servers.

Configuration is stored at `%APPDATA%\Clopen\config.json` for the current Windows user. Removing the portable application does not automatically delete this file; users may back it up or delete it themselves. Information voluntarily submitted through GitHub Issues, Discussions, or private security reports is processed by GitHub under its policies, so remove personal paths, usernames, and unnecessary application lists before submitting.

If a future release adds network functionality, this notice must be updated before the feature is enabled and the change must be disclosed clearly in the Release Notes.
