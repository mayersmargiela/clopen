# 安全政策 / Security Policy

## 中文

当前受支持版本为最新公开 Release。

请不要为安全漏洞创建公开 Issue。请使用 GitHub 仓库 **Security → Report a vulnerability** 私下报告，并提供受影响版本、复现条件、潜在影响和可行的缓解方式。报告中不要包含无关的个人数据。

维护者会尽快确认报告、评估影响，并在修复可用后协调披露。Clopen 的进程控制边界属于安全敏感区域：任何可能结束非本次会话进程的行为都应按安全问题报告。

## English

The latest public release is the currently supported version.

Do not open a public Issue for a vulnerability. Use **Security → Report a vulnerability** in the GitHub repository and include the affected version, reproduction conditions, potential impact, and any known mitigation. Do not include unrelated personal data.

The maintainer will acknowledge the report as soon as practical, assess impact, and coordinate disclosure after a fix is available. Clopen's process-control boundary is security-sensitive: any behavior that may terminate a process outside the current Clopen session should be reported as a security issue.
