- 在 [`05b66d9`](https://github.com/mayersmargiela/clopen/commit/05b66d9610e032758a28aa7f89a0ca44c2a809b5) 中把 `actions/upload-artifact` 更新到 v5。
- 修复后，main 分支和 v0.2.7 标签构建均成功：[运行 31699381771](https://github.com/mayersmargiela/clopen/actions/runs/31699381771)、[运行 31699660347](https://github.com/mayersmargiela/clopen/actions/runs/31699660347)、[运行 31699856898](https://github.com/mayersmargiela/clopen/actions/runs/31699856898)。

### 2026-08-13 to 2026-08-14: Windows CI diagnosis and repair

- The second attempt of the initial CI run failed after all 16 unit tests had passed. The release self-check failed because the editable install created `src/clopen.egg-info` before the clean-source check, which correctly rejected the generated directory. Evidence: [failed run](https://github.com/mayersmargiela/clopen/actions/runs/31699154718).
- Commit [`b51b291`](https://github.com/mayersmargiela/clopen/commit/b51b2910ea21b9096e6d78b604970b17446ea31f) moved the release self-check before dependency installation and updated `actions/checkout` and `actions/setup-python` to compatible versions.
- Commit [`05b66d9`](https://github.com/mayersmargiela/clopen/commit/05b66d9610e032758a28aa7f89a0ca44c2a809b5) updated `actions/upload-artifact` to v5.
- After the fixes, both main-branch and v0.2.7 tag builds succeeded: [run 31699381771](https://github.com/mayersmargiela/clopen/actions/runs/31699381771), [run 31699660347](https://github.com/mayersmargiela/clopen/actions/runs/31699660347), and [run 31699856898](https://github.com/mayersmargiela/clopen/actions/runs/31699856898).
