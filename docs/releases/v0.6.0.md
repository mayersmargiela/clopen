# Clopen Liquid Glass v0.6.0

[中文](#中文) · [English](#english)

## 中文

Clopen v0.6.0 将 Classic 的组合启动与会话级安全关闭能力带入新的 Liquid Glass 界面。

### 主要变化

- 统一主窗口、组合编辑器、软件选择器、设置与托盘菜单的玻璃视觉。
- `Ctrl+Shift+E` 打开持久化原生 Qt 快捷菜单。
- 快捷键采用后台物理按键检测，并通过 Qt 队列信号安全返回 GUI 线程。
- 保持兼容 `%APPDATA%\Clopen\config.json`，Classic 用户无需迁移组合配置。
- 增加 QML、运行链与 Windows 快捷键冒烟测试。

### 安全边界

Clopen 仍然只关闭本次由它启动并成功登记的进程，不按进程名全局结束程序。浏览器复用实例、文件、文件夹和 UWP 启动项仍不保证可受控关闭。关闭应用可能导致未保存内容丢失。

### Windows 提示

当前发布包未使用商业代码签名证书，Windows 可能显示“未知发布者”。请从本仓库 Releases 下载，并使用随附的 SHA-256 文件核对完整性。

## English

Clopen v0.6.0 brings Classic's grouped launching and session-safe closing into a new Liquid Glass interface.

### Highlights

- A consistent glass interface across the main window, group editor, software picker, settings, and tray menu.
- A persistent native Qt quick menu opened with `Ctrl+Shift+E`.
- Background physical-key detection with a queued Qt signal back to the GUI thread.
- Continued compatibility with `%APPDATA%\Clopen\config.json`; Classic users do not need to migrate their groups.
- Added QML, runtime-chain, and Windows hotkey smoke tests.

### Safety boundaries

Clopen still closes only processes that it started and successfully registered in the current session. It never terminates programs globally by executable name. Reused browser instances, files, folders, and UWP launch entries are still not guaranteed to be controllable. Closing applications may discard unsaved work.

### Windows notice

The current package is not signed with a commercial code-signing certificate, so Windows may show an “Unknown publisher” warning. Download only from this repository's Releases page and verify the included SHA-256 checksum.
