# Clopen Classic v0.2.7 — Initial Public Release

## 中文

这是 Clopen 的首次公开版本。它帮助 Windows 用户保存并一次打开一组软件，并通过会话级进程登记降低误关其他程序的风险。

### 功能

- 创建、编辑和运行软件组合。
- 搜索本机已安装软件。
- 通过 `Ctrl+Shift+E` 打开快捷菜单。
- 只请求关闭本次由 Clopen 启动并登记的进程。

### 已知边界

- 浏览器复用实例、文件、文件夹和 UWP 应用默认不保证可受控关闭。
- Windows 11 是本次正式验证平台；Windows 10 尚未完成正式实测。
- 当前便携包未使用商业代码签名证书，Windows 可能显示“未知发布者”。请从本仓库 Release 下载并核对 SHA-256。

## English

This is Clopen's initial public release. It helps Windows users save and open a group of applications together while reducing the risk of closing unrelated programs through session-level process registration.

### Features

- Create, edit, and run application groups.
- Search applications installed on the current PC.
- Open the quick menu with `Ctrl+Shift+E`.
- Request closing only for processes started and registered by the current Clopen session.

### Known boundaries

- Reused browser instances, files, folders, and UWP apps are not guaranteed to be controllable.
- Windows 11 is the formally verified platform for this release; Windows 10 has not completed formal testing.
- The portable package is not signed with a commercial code-signing certificate, so Windows may show “Unknown publisher.” Download it from this repository's Release page and verify its SHA-256 checksum.
